# Practical Labs

Store lab notes here, preferably one Markdown file per experiment.

Suggested filename pattern:

```text
YYYY-MM-DD-topic.md
```

For each lab, record:

- **Question:** What behavior are you investigating?
- **Environment:** Distribution, kernel version, and whether this is a VM/WSL/host.
- **Commands:** Commands executed, with sensitive data removed.
- **Observation:** What actually happened?
- **Explanation:** Which OS mechanism explains the result?
- **Docker connection:** Where does this concept appear in Docker?
- **Follow-up:** What remains unclear?

Use a disposable VM for experiments that change networking, mounts, cgroups, security settings, or system services.
